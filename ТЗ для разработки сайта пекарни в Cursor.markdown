# Техническое задание для разработки сайта пекарни в Cursor

## 1. Общая концепция
Сайт пекарни должен быть современным, эстетичным и визуально привлекательным, вдохновлённым стилем сайта Koenigsegg, но адаптированным под тематику пекарни. Дизайн — чистый, с акцентом на высококачественные изображения выпечки, тёплую цветовую палитру и плавные анимации. Цель — создать интуитивно понятный интерфейс, чтобы посетители могли легко найти информацию и захотели заказать продукцию.

## 2. Структура сайта
- **Верхняя навигационная панель (шапка)**: Логотип слева, меню справа (Главная, Продукты, О нас, Контакты). Фиксированная при прокрутке.
- **Подвал (футер)**: Адрес, часы работы, контакты, ссылки на соцсети, копирайт.
- **Главная страница**: Герой-секция с изображением и текстом, блок с популярными продуктами, краткий анонс пекарни.
- **Страница "Продукты"**: Сетка карточек товаров с фото, названием, описанием, ценой. Детальная страница для каждого продукта.
- **Страница "О нас"**: История пекарни, фото команды или процесса выпечки, философия.
- **Страница "Контакты"**: Форма обратной связи, контактные данные, интерактивная карта.

## 3. Дизайн и анимации
- **Цветовая палитра**: Тёплые тона (коричневый, кремовый, золотистый).
- **Шрифты**: Современные и читаемые (например, Montserrat, Open Sans).
- **Анимации**: Параллакс-скроллинг, плавное появление элементов, ховер-эффекты, плавные переходы между страницами.

## 4. Функционал
- **Адаптивность**: Полная поддержка мобильных устройств, планшетов и десктопов.
- **Скорость загрузки**: Оптимизация изображений, ленивая загрузка, сжатие CSS/JS.
- **SEO**: Семантическая вёрстка, alt-тексты, мета-теги, данные NAP.

## 5. Технологии и разработка в Cursor
- **Фронтенд**: HTML5, CSS3, JavaScript.
- **Анимации**: CSS transitions/animations, GSAP или ScrollMagic.
- **Бэкенд** (опционально): CMS (WordPress + WooCommerce) или Node.js.
- **Хостинг**: Надёжный сервер с SSL.

### Особенности разработки в Cursor
- Используйте автокомплит и подсказки ИИ для ускорения написания кода.
- Генерируйте повторяющиеся элементы (например, карточки товаров) с помощью ИИ.
- Применяйте ИИ для создания базовых стилей и анимаций, затем дорабатывайте их вручную.
- Используйте ИИ для оптимизации кода и исправления ошибок.

## 6. Дополнительно
- **Онлайн-заказ** (опционально): Корзина, выбор товаров, интеграция с оплатой.
- **Отзывы**: Карусель с отзывами на главной или странице "О нас".

## 7. Итог
Сайт станет мощным инструментом для привлечения клиентов, сочетая эстетику, функциональность и удобство использования. Разработка в Cursor с использованием ИИ ускорит процесс и поможет создать качественный продукт.
